Deck Playbook

Looking to teach a friend about your deck? Or just teaching a friend Magic for the first time? Follow these steps.

  1. Make sure your Archidekt deck is public.
  2. Copy the share link.
  3. Paste it below and click Generate.
  4. Send your friend the playbook (or open it together).
How this works / troubleshooting

Public Archidekt decks only. The tool fetches the deck via the public API (through a CORS proxy because Archidekt only allows localhost), extracts the commander and cards, then builds a self-contained HTML playbook.

The banner uses the deck’s featured art with a slow Ken-Burns zoom + gentle glow so it feels alive without needing video files.

If generation fails, make sure the deck is public and try again. You can also open the finished HTML offline once downloaded.

Share this file with friends. They open it in any browser, paste their Archidekt link, and download the playbook. No accounts or installs required.
