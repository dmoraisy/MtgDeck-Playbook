Archidekt Playbook Generator
Deploy
1. Proxy (Cloudflare Worker)
Go to Cloudflare Workers and create a new Worker.
Paste the contents of worker.js.
Deploy and copy the Worker URL (e.g. https://archidekt-proxy.yourname.workers.dev).
2. GitHub Pages
Create a new public GitHub repo.
Upload index.html.
Edit index.html and replace YOUR-WORKER-NAME.workers.dev with your actual Worker URL.
Enable GitHub Pages (Settings → Pages → Deploy from main branch).
3. Share
Text the GitHub Pages URL. Friends paste an Archidekt share link and generate a playbook.
